Cookie-Based Authentication Demo

This example demonstrates a simple authentication system using cookies and Python CGI scripts.

Features:

  • User registration with JSON storage
  • Login/logout functionality
  • Cookie-based session management
  • Protected pages accessible only when logged in
  • All data stored in JSON files

How to use:

  1. Register: Create a new account on the register page
  2. Login: Sign in with your credentials on the login page
  3. Access Protected Content: Visit the protected page
  4. Logout: Click the logout button to end your session
