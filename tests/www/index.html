🚀 webserv Test Server

Welcome to the webserv test page! This server demonstrates all required features.

Features Implemented:

  • ✅ Static file serving (GET)
  • ✅ Multiple servers and ports
  • ✅ Virtual hosting (server_name)
  • ✅ File upload (POST)
  • ✅ File deletion (DELETE)
  • ✅ CGI execution (.py scripts)
  • ✅ Directory listing (autoindex)
  • ✅ Custom error pages
  • ✅ HTTP redirects (301, 302)
  • ✅ Worker connections limit
  • ✅ Idle timeout handling
  • ✅ Advanced logging system
  • ✅ Non-blocking I/O (kqueue/epoll)
